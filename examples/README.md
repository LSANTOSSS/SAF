# Casos Demonstrativos

Esta área reúne exemplos de aplicação do SAF e do MER.

## Regra de construção

Os casos deste diretório devem ser:

- fictícios; ou
- baseados exclusivamente em informações públicas.

Nenhum case deve ser uma cópia, adaptação direta ou simples anonimização de projeto corporativo.

## Objetivo dos casos

Os exemplos devem mostrar o processo, não apenas o documento final.

Um case completo poderá incluir:

```text
Briefing inicial
      ↓
Descoberta
      ↓
Fontes
      ↓
Gaps
      ↓
Análise
      ↓
Decisões
      ↓
Requisitos
      ↓
Cenários
      ↓
Especificação
      ↓
Rastreabilidade
```

Isso permite observar não apenas **o que foi especificado**, mas **como a especificação foi construída**.

## Primeiro case

O primeiro domínio fictício será definido após a consolidação da versão inicial do MER.

A escolha deve privilegiar um cenário que permita demonstrar:

- múltiplos atores;
- regras de negócio;
- estados;
- integrações;
- exceções;
- conflitos;
- requisitos funcionais e não funcionais;
- critérios de aceite;
- decisões rastreáveis.
