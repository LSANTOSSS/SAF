# Case Study — Room Booking

**Version:** v0.3.0  
**Status:** Demonstrative, fictional, clean-room

Este case demonstra a aplicação pública do **MER — Método de Engenharia de Requisitos** a uma demanda fictícia: criar uma solução para reserva de salas compartilhadas em um escritório.

## Objetivo do case

Demonstrar, de ponta a ponta, como uma demanda incompleta evolui para uma especificação funcional rastreável sem transformar suposições em requisitos.

```text
Demanda → Fontes e Evidências → Descoberta → Análise → Gaps → Decisões → Requisitos → Cenários → Validação → Especificação → Revisão
```

## Premissa clean-room

Todo o domínio, atores, regras, decisões e exemplos deste diretório são fictícios e foram criados exclusivamente para demonstrar o SAF. Nenhum conteúdo depende de código proprietário, documentação privada, sistemas internos, dados reais, regras confidenciais ou infraestrutura de terceiros.

## O que observar

Questões como conflito de agenda, duração máxima, cancelamento e permissões surgem primeiro como **gaps**. Somente após decisões explícitas elas passam a sustentar requisitos.
