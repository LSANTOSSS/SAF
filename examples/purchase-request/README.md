# Case Study — Purchase Request Approval

**Version:** v0.10.0  
**Status:** Demonstrative, fictional, clean-room

Terceiro case público do SAF, criado para demonstrar o **MER — Método de Engenharia de Requisitos** em aprovação, alçadas e segregação de responsabilidades.

Todo o domínio, atores, valores, regras e decisões são fictícios e independentes de qualquer organização real.

## Objetivo

Demonstrar capacidades complementares aos cases anteriores:

- aprovação e rejeição;
- alçadas por valor;
- múltiplos níveis;
- bloqueio de autoaprovação;
- devolução para ajuste;
- expiração;
- cancelamento;
- trilha de decisão.
