# 05 — Critérios de Aceite

| ID | Critério |
|---|---|
| CA-001 | Solicitação válida pode ser salva em `Rascunho` |
| CA-002 | R$ 4.000 deve exigir N1 |
| CA-003 | R$ 10.000 deve exigir N2 |
| CA-004 | R$ 25.000 deve exigir N2 e depois N3 |
| CA-005 | Tentativa de autoaprovação deve ser rejeitada |
| CA-006 | Devolução sem comentário deve ser rejeitada |
| CA-007 | Rejeição sem justificativa deve ser rejeitada |
| CA-008 | Solicitação devolvida e alterada deve iniciar novo ciclo |
| CA-009 | Pendência por 10 dias corridos deve expirar |
| CA-010 | Eventos relevantes devem constar no histórico |
| CA-011 | Solicitação ainda não autorizada pode ser cancelada pelo solicitante |
| CA-012 | Solicitação autorizada não pode ser cancelada pelo fluxo comum |
| CA-013 | Acima de R$ 20.000, somente N2 não autoriza |
| CA-014 | Acima de R$ 20.000, N2 e N3 aprovados autorizam |
