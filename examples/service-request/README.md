# Case Study — Service Request Management

**Version:** v0.9.0  
**Status:** Demonstrative, fictional, clean-room

Este case demonstra a aplicação pública do **MER — Método de Engenharia de Requisitos** a uma demanda fictícia de gestão de solicitações de serviço.

## Objetivo do case

Demonstrar que o mesmo método utilizado no case `room-booking` pode ser reutilizado em um domínio diferente, agora com foco em **workflow, estados, prioridades, responsabilidades, prazos e auditoria**.

```text
Demanda → Fontes e Evidências → Descoberta → Gaps → Decisões → Requisitos → Critérios → Rastreabilidade → Especificação
```

## Premissa clean-room

Todo o domínio, atores, regras, dados e decisões deste diretório são fictícios e foram criados exclusivamente para demonstrar o SAF. O case não representa processo interno, sistema real ou regra de negócio de qualquer organização.

## O que observar

Neste case, regras importantes não aparecem prontas na demanda. Prioridade, SLA, transições de estado, reabertura, cancelamento e permissões surgem como **gaps** e só passam a sustentar requisitos depois de decisões explícitas.
