# Checklist — Revisão

## Clareza
- [ ] A linguagem é direta?
- [ ] Termos são usados de forma consistente?
- [ ] Há ambiguidades evitáveis?
- [ ] O sujeito e o comportamento esperado estão identificáveis?

## Completude
- [ ] O fluxo principal está coberto?
- [ ] Alternativas relevantes foram consideradas?
- [ ] Exceções e erros importantes estão descritos?
- [ ] Restrições conhecidas estão registradas?

## Consistência
- [ ] Requisitos não se contradizem?
- [ ] Regras estão coerentes com decisões?
- [ ] Critérios de aceite não introduzem regra nova?
- [ ] Escopo e fora de escopo estão coerentes?

## Verificabilidade
- [ ] Requisitos permitem avaliação objetiva?
- [ ] Termos vagos foram evitados ou qualificados?
- [ ] Critérios de aceite possuem resultado observável?

## Rastreabilidade
- [ ] Requisitos relevantes possuem origem compreensível?
- [ ] Decisões materiais estão relacionadas aos itens afetados?
- [ ] Alterações podem ser avaliadas por impacto?

## Incerteza
- [ ] Hipóteses continuam identificadas?
- [ ] Gaps abertos possuem status?
- [ ] Nenhuma inferência foi apresentada como fato?

## Gate
- [ ] A revisão humana foi realizada?
- [ ] Não existem bloqueios materiais antes da aprovação?
