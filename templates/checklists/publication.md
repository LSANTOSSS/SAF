# Checklist — Publicação

Este checklist protege a fronteira pública do SAF antes de qualquer publicação.

## Origem
- [ ] O conteúdo foi criado para o SAF ou deriva apenas de fonte pública/autorizada?
- [ ] Nenhum trecho foi copiado de documentação privada?
- [ ] Nenhum código proprietário está presente?
- [ ] Nenhuma regra confidencial foi transplantada?

## Identificadores e dados
- [ ] Não há nomes internos de sistemas ou serviços?
- [ ] Não há endpoints privados?
- [ ] Não há credenciais, tokens, chaves ou segredos?
- [ ] Não há dados reais de clientes, usuários ou operações?
- [ ] Não há nomes, IDs ou referências que revelem contexto privado?

## Clean-room
- [ ] Exemplos são fictícios ou públicos?
- [ ] O case pode ser entendido sem contexto corporativo?
- [ ] A terminologia foi reescrita de forma independente quando necessário?
- [ ] O conteúdo não é apenas uma cópia renomeada de projeto real?

## Qualidade
- [ ] Links internos funcionam?
- [ ] O README e o roadmap refletem a versão publicada?
- [ ] O CHANGELOG foi atualizado?
- [ ] O conteúdo foi revisado quanto a clareza e consistência?

## IA
- [ ] Conteúdo gerado com apoio de IA foi revisado por humano?
- [ ] IA não foi tratada como fonte oficial?
- [ ] Inferências relevantes foram verificadas antes da publicação?

## Gate final
- [ ] A publicação respeita `docs/00-governance/publication-safety.md`?
- [ ] Não há nenhum bloqueio de segurança ou confidencialidade?
