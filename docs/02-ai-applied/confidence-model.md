# Modelo de Confiança

| Classe | Significado | Uso |
|---|---|---|
| Confirmado | Sustentado por fonte autorizada ou decisão validada | Pode alimentar artefato com rastreabilidade |
| Derivado | Inferência coerente a partir de evidências | Exige revisão |
| Hipótese | Possibilidade sem confirmação suficiente | Orienta investigação |
| Gap candidato | Ausência, conflito ou ambiguidade percebida | Deve ser confirmado |
| Não sustentado | Afirmação sem base suficiente | Não deve alimentar requisito |

**Confiança linguística não equivale a confiança epistemológica.**

Somente nova evidência, validação ou decisão pode elevar a classificação. Reformular o texto ou perguntar novamente ao modelo não aumenta sua sustentação.
