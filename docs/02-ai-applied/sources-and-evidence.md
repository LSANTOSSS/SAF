# Fontes e Evidências com apoio de IA

IA pode trabalhar **sobre** fontes; ela não substitui a fonte.

```text
Fonte autorizada → evidência → análise assistida → classificação → verificação → MER
```

## Regras
- preserve referência para reencontrar a origem;
- diferencie evidência de interpretação;
- confirme afirmações materiais na fonte;
- sinalize quando a fonte não responde;
- não complete lacunas sem rotulá-las.

Gap encontrado por IA é **gap candidato** até revisão. Requisito proposto por IA deve ser rastreado até evidência e/ou decisão válida antes de entrar na especificação.

Conhecimento geral do modelo pode sugerir investigação, mas não é evidência específica do projeto.
