# IA aplicada à Análise de Sistemas

Este módulo descreve como o SAF utiliza IA como instrumento de apoio à Engenharia de Requisitos, sem atribuir ao modelo autoridade sobre fontes, decisões ou aprovação.

## Princípio operacional
```text
Contexto autorizado → IA analisa/organiza/questiona → saída classificada → verificação → revisão humana → artefato do MER
```
