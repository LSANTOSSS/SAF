# Prompts seguros e genéricos

## Descoberta
> Analise apenas o contexto fornecido. Separe fatos explícitos, inferências, hipóteses e gaps. Não invente respostas para informações ausentes. Para cada gap, explique impacto e pergunta de resolução.

## Revisão
> Revise os requisitos quanto a clareza, consistência, verificabilidade, duplicidade e ambiguidades. Não altere decisões funcionais. Separe problemas de propostas de correção.

## Comparação
> Compare as fontes A e B apenas pelo conteúdo fornecido. Identifique convergências, divergências e informações exclusivas. Não escolha qual está correta sem evidência adicional.

## Rastreabilidade
> Para cada requisito, identifique evidências, gaps e decisões fornecidas que o sustentam. Marque como não sustentado o que não puder ter origem demonstrada.

## Busca de gaps
> Procure exceções, estados indefinidos, responsabilidades ambíguas, conflitos e erros ausentes. Trate achados como gaps candidatos até revisão humana.

Um prompt seguro explicita escopo, fontes permitidas, proibição de invenção, classificação, referências, formato e pontos reservados à decisão humana.
