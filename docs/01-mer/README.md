# MER — Método de Engenharia de Requisitos
O **MER** é o núcleo metodológico do SAF — System Analysis Framework. Seu objetivo é transformar uma demanda em especificação funcional clara, rastreável, revisável e validável, preservando a diferença entre o que é conhecido, interpretado e ainda precisa ser decidido.

## Fluxo
```text
Demanda → Fontes e Evidências → Descoberta → Análise → Gaps → Decisões → Requisitos → Cenários → Validação → Especificação → Revisão
```
O fluxo é iterativo: nova evidência pode reabrir análise; validação pode revelar gaps; decisões podem alterar requisitos.

## Templates

## IA
IA pode apoiar organização, comparação, análise, perguntas e revisão. IA não é fonte oficial e não possui autoridade para transformar inferência em fato, hipótese em decisão ou gap em requisito aprovado. Decisão e aprovação permanecem humanas.

## Escopo público
Esta versão é independente e clean-room. Seus conceitos e exemplos são genéricos e não dependem de sistemas, documentação, código, dados ou infraestrutura de terceiros.
