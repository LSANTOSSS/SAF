# SAF 1.0 — Stable Public Framework

A v1.0 consolida o SAF como um framework público para transformar demandas incompletas em especificações funcionais rastreáveis.

## Capacidades estáveis

- MER como núcleo metodológico;
- classificação explícita de evidência e incerteza;
- gaps antes de decisões;
- rastreabilidade bidirecional;
- revisão humana como gate;
- IA como apoio, não autoridade;
- Markdown como fonte controlada;
- pipeline executável;
- exportação Markdown, HTML e DOCX;
- validação em três domínios fictícios e independentes.

## Contrato conceitual

```text
Demanda
  ↓
Fontes e evidências
  ↓
Descoberta
  ↓
Gaps
  ↓
Decisões
  ↓
Requisitos e regras
  ↓
Critérios de aceite
  ↓
Rastreabilidade
  ↓
Especificação
  ↓
Validação / exportação
  ↓
Revisão humana
```
